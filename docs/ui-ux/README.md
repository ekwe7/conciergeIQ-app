# UI/UX Prototypes and Mockups

This directory contains the visual prototypes and screen mockups for the Guest Experience CRM (`conciergeIQ`).

## Structure

- **[`png/`](./png/)**: High-fidelity screen renders and mockups:
  - **Guest Application:**
    - `G01-guest-welcome.png` — QR entry and landing
    - `G02-guest-menu.png` — Menu browsing and categories
    - `G03-guest-item-detail.png` — Item modal and customizations
    - `G04-guest-cart-checkout.png` — Cart summary and order placement
    - `G05-guest-order-tracking.png` — Real-time order status tracking
    - `G06-guest-amenities.png` — Room service requests (towels, toiletries)
    - `G07-guest-ai-concierge.png` — Future stage AI concierge helper
    - `G08-guest-error-states.png` — Inactive stay / expired session error views
  - **Dashboard Application:**
    - `00-design-system.png` — Design system visual overview
    - `01-landing-page.png` — Landing / marketing overview
    - `02-staff-login.png` — Staff authentication
    - `03-live-orders-board.png` — Staff live order queue
    - `04-order-detail-drawer.png` — Order details and status actions
    - `05-rooms-and-stays.png` — Room management
    - `06-check-in-check-out.png` — Reception stay management
    - `07-menu-management.png` — Menu items & availability toggles
    - `08-payments.png` — Payment tracking & mark-as-paid
    - `09-qr-codes.png` — Room QR code generator and printing
    - `10-staff-and-roles.png` — Staff permissions
    - `11-activity-log.png` — Hotel audit trail
    - `12-owner-insights.png` — Owner analytics and reporting
    - `13-reconciliation-report.png` — Daily financial reconciliation
    - `14-escalation-rules.png` — Operational alerts and notifications
    - `15-hotel-settings-branding.png` — Hotel profile and branding
    - `16-staff-mobile-and-offline.png` — Responsive staff view on tablet/mobile

- **[`src/`](./src/)**: HTML prototypes, stylesheet (`ciq.css`), and the Python generation script (`build.py`).
